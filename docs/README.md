| [nexitally-workflow.md](nexitally-workflow.md) | You are wiring Nexitally into a stable local profile |
| [parser-contract.md](parser-contract.md) | You need the exact keep / drop rules of `nexitally-node-parser.js` |
| [local-verification.md](local-verification.md) | You want to run the examples on a computer |
| [troubleshooting.md](troubleshooting.md) | A refresh failed or the server list looks wrong |

| [writing-a-parser.md](writing-a-parser.md) | You are adding another personal parser or fixture |
