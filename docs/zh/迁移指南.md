# 迁移指南

目的：以后只刷新 Nexitally 的**节点资源**，不再每次「配置文件 → 下载」覆盖本地策略、分流和重写。

## 前提

- 节点是 AnyTLS 时，Quantumult X 需要 1.6.0（或 1.5.6 TF 914+）。
- 已经有一份你愿意长期用的本地配置。
- 完整配置的私有 URL 只存在手机/电脑上。

## 步骤

1. 在 `[general]` 写入本仓库的解析器（GitHub raw 为准）：

   ```ini
   resource_parser_url = https://raw.githubusercontent.com/sapphireran/quanx-resource-parsers/main/nexitally-node-parser.js
   ```

2. 把私有 URL 加到 `[server_remote]`，**必须** `opt-parser=true`：

   ```ini
   [server_remote]
   <YOUR_PRIVATE_NEXITALLY_QUANTUMULT_X_URL>, tag=Nexitally, opt-parser=true, update-interval=21600, enabled=true
   ```

3. 本地策略用 `resource-tag-regex=^Nexitally` 接住节点，不要写死每一个城市名。样例见 `lab/profiles/keep-local-policy.snippet.conf`。

4. 在 App 里刷新 **Server Resources → Nexitally**。流量行和 `[Premium]` 占位不应出现。

5. 之后不要再把「配置文件 → 下载」当作日常更新。

完整英文步骤：[migration-cookbook.md](../migration-cookbook.md)。排错：[troubleshooting.md](../troubleshooting.md)。
