# Nexitally 节点解析器说明

`nexitally-node-parser.js` 跑在 Quantumult X 的资源解析器沙箱里。客户端在设备上下载你的**私有**完整配置，把正文放进 `$resource.content`。脚本只读正文，抽出第一段 `[server_local]`，把可用节点行交给 `[server_remote]`。

仓库里没有订阅 URL、账户 ID、节点密码。样例主机一律是 `.example.invalid`。

## 会保留

行首（忽略大小写，等号前可以有空格）为：

`anytls`、`shadowsocks`、`vmess`、`vless`、`trojan`、`http`、`socks5`

## 会丢掉

- 空行
- 以 `;`、`#`、`//` 开头的注释（官方 `sample.conf` 的注释规则）
- 其它协议前缀（例如 `hysteria2`）
- 行内出现 `[Premium]`、`Traffic`、`Expire`、`Reset`、`Days Left`、`流量`、`到期`、`剩余`、`套餐`
- trim 之后完全相同的重复行
- `[server_local]` **之后**下一个 `[分段]` 里的内容（包括后面的 `[Premium]`）

`Reset` 是子串：`tag=Preset 01` 也会被丢掉。这是刻意写进样例里的限制，不是建议你去改节点名。

## 错误

| 情况 | Quantumult X 里会看到 |
| --- | --- |
| 找不到 `[server_local]` | `Nexitally parser: [server_local] section was not found.` |
| 找到了但过滤后为空 | `Nexitally parser: no usable server entries were found.` |

脚本不会去读 `$resource.link`，也不会申请换 UA 重下。

更细的规则和对照表见 [parser-spec.md](../parser-spec.md) 与 [keep-drop-matrix.md](../keep-drop-matrix.md)。
