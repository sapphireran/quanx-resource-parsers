Nexitally parser pipeline

Personal, source-faithful sketch of nexitally-node-parser.js. Quantumult X downloads the managed full configuration. This script keeps server lines and throws the rest away.

In

$resource.content — a whole Quantumult X profile, often with [general], [policy], [server_local], filters, rewrite, MitM.

The private URL stays in Quantumult X. The script never reads $resource.link.

Out

$done({ content }) — kept server lines, one per line, no section header.

$done({ error }) — either no [server_local], or the sieve kept nothing.

Sieve

BOM strip → CRLF to LF → first [server_local]
    → trim each line
    → drop empty / ;#// comments
    → drop if not anytls|shadowsocks|vmess|vless|trojan|http|socks5 =
    → drop if [Premium]|Traffic|Expire|Reset|Days Left|流量|到期|剩余|套餐
    → drop exact duplicates
    → join keeps with \\n
