# Profile snippets

These fragments belong in a **local** Quantumult X profile. They are not parser input.

| File | Use |
| --- | --- |
| `01-general-parser.snippet.conf` | `resource_parser_url` only |
| `02-server-remote.snippet.conf` | Nexitally resource line with a placeholder URL |
| `03-policy-kept-local.snippet.conf` | Groups that follow `tag=Nexitally` |
| `assembled-personal-profile.snippet.conf` | The three above plus harmless DNS / filter stubs |

Parser input fixtures are under [`../cases/`](../cases/).
