# Personal profile snippets

Copy these fragments into a local Quantumult X profile. Replace
`<YOUR_PRIVATE_NEXITALLY_QUANTUMULT_X_URL>` on the device only.

| File | Section |
| --- | --- |
| `general-parser.conf` | `resource_parser_url` |
| `server-remote.conf` | Nexitally server resource with `opt-parser=true` |
| `policy-with-resource-tag.conf` | Groups that follow `tag=Nexitally` |
| `local-profile.skeleton.conf` | Minimal local profile that keeps filters and rewrites |

None of these files contain a live subscription URL.
